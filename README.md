### Inventory (PART 5)
- This [table](https://github.com/shadsluiter/ExcelExamples) is a database. A car inventory. 
- the dataset was first transformed to the excel format. 
- to get the abbreviation of company name of the Card ID. left function was used.
- VLOOKUP function was used to get the full company name. 
- mid function was used to get the abbreviation model name. 
- Vlookup function was used to get the full model name. 
- substitute and mid function was used to get the released or manufactured year. 
- if statement was used to get the age. (solving the y2k problem). 
- concatenate, UPPER, left and right function was used to get the new ID CAR. 
- Pivot table was used to get the summary on the Top drivers with the most miles driven.
